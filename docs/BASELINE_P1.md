## 4. 怎么读这两个相反的结果

- 实验1 与实验2 的结论**不矛盾**：n-gram 是记忆型模型，扩语料带来的收益主要体现在「与训练语料同源的文本」上；对按文档划分被切到留出集、训练时**完全没见过**的 TRPG 节点，词表覆盖的收益不足以抵消分布迁移。
- **真实部署的预期**：生产环境会把 paotuan 全量纳入训练（不留出），此时面对的是「已见过的模组内容」，收益方向同实验1（正）。实验2 衡量的是**泛化到全新节点**的能力 —— 那是 n-gram 的本质天花板，应由 P2 的 CNN 来解决（卷积能泛化局部模式，而非死记 n-gram）。
- 方法学提醒：若只看实验1 会**高估**语料的价值，只看实验2 会**低估**它。两个留出集都报，才是可判定的。
