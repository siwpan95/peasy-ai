- top-1：马尔科夫最优 34.81% （Markov n=3） vs CNN 43.95% → 差 +9.14pp，CNN 更优

| window=8 dim=32 f=32 ep=40 | 54.98 | 42.20% | 49.77% | 13.6s |
| window=8 dim=64 f=64 ep=40 | 52.06 | 42.66% | 48.85% | 66.3s |
| window=12 dim=48 f=48 ep=40 | 58.79 | 42.38% | 48.48% | 87.2s |
| window=8 dim=32 f=64 ep=60 | 53.37 | 43.40% | 48.94% | 68.6s |

两条实测结论：

1. **小模型就够** —— 最优配置只花 4.2s；把参数量翻 4 倍、耗时涨到 66s，top-1 反而略降（42.66%）。7950 token 的语料撑不起更大的容量。
2. **更短的 window 更好** —— window=4 胜过 8 与 12。小语料下加长上下文引入的多半是噪声而非信息，这与「CNN 能捕获长程依赖」的直觉相反，也说明**架构优势受语料规模制约**。
