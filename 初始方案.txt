#### 1. 修复反射逻辑的局限性
目前的 reflect 函数使用 replace，这会导致“我们”变成“我们”（因为‘我’被替换了）。建议使用单词边界或字典映射优化，但对于简单场景，我们可以加个顺序保护：
```python
def reflect(self, text):
    """优化版：防止 '我们' -> '我们'"""
    reflections = [
        ("我是", "你是"),
        ("你是", "我是"),
        ("我的", "你的"),
        ("你的", "我的"),
        ("我", "你"),
        ("你", "我"),
    ]
    for old, new in reflections:
        text = text.replace(old, new)
    return text
```

## 二、核心思路（很重要）
1. 把所有“已知问题”当成语料
    - 规则里的模式
    - 用户教过的 memory
2. 用 TF‑IDF 向量化
3. 计算用户输入 vs 已知问题的余弦相似度
4. 超过阈值 → 用最相似问题的答案
5. 低于阈值 → 回退到原来的正则
👉 这样你既有“语义理解”，又不会丢失原有逻辑。

### 2️⃣ 改造 SimpleAI
```python
class SimpleAI:
    def __init__(self):
        self.rules = {
            r'你好|嗨|hello|hi': ['你好呀！今天想聊什么？'],
            r'你叫什么|你是谁': ['我叫小简，一个用 Python 写的 AI。'],
            r'谢谢|感谢': ['不客气！'],
            r'再见|拜拜|bye': ['再见！'],
            r'.*': ['这个挺有意思的，能再说详细点吗？']
        }

        self.memory = {}  # 精确问答
        self.corpus = []  # 所有已知问题
        self.answers = [] # 对应答案

        self.vectorizer = None
        self.tfidf_matrix = None

        self._build_corpus()

    def _build_corpus(self):
        """构建 TF‑IDF 语料"""
        self.corpus.clear()
        self.answers.clear()

        # 规则
        for pattern, responses in self.rules.items():
            self.corpus.append(pattern)
            self.answers.append(random.choice(responses))

        # 记忆
        for q, ans_list in self.memory.items():
            self.corpus.append(q)
            self.answers.append(random.choice(ans_list))

        texts = [tokenize(t) for t in self.corpus]
        self.vectorizer = TfidfVectorizer()
        self.tfidf_matrix = self.vectorizer.fit_transform(texts)
```

### 3️⃣ 新增：语义匹配方法
```python
    def tfidf_reply(self, message, threshold=0.3):
        """TF‑IDF 相似度匹配"""
        if self.tfidf_matrix is None:
            return None

        vec = self.vectorizer.transform([tokenize(message)])
        sims = cosine_similarity(vec, self.tfidf_matrix)[0]

        best_idx = np.argmax(sims)
        score = sims[best_idx]

        if score >= threshold:
            return self.answers[best_idx]
        return None
```

四、引擎核心设计
1. 事件调度器
维护一个“当前场景ID”指针，每次选择后：
1. 根据选项的 next 跳转到新场景；
2. 若跳转到的场景ID为 end_xxx 或属性检查触发结局，则进入结局处理。
3. 属性系统
维护一个字典 attributes，并提供修改接口。每次应用选项效果后，检查是否有属性 ≤0 或 ≥上限，触发对应结局（配置于 endings）。
1. 条件求值器
支持的条件类型：
· {"attr": "religion", "min": 20} ：属性大于等于20
· {"attr": "people", "max": 80} ：属性小于等于80
· {"has_clue": "letter"} ：已收集线索“letter”
· {"flag": "chose_tax"} ：之前选择过标记为“chose_tax”的选项（选项可设置 flag 字段）
· 复合条件：{"and": [...]}，{"or": [...]}
条件求值器独立于剧情数据，可扩展。
1. 存档管理
保存当前状态：scene_id、attributes、flags、clues。支持导出为 JSON，供将来读档。

### 第二步：条件求值器 (engine/conditions.py) —— 难点突破
这是你方案中的精华。我们需要一个递归函数来解析嵌套的逻辑（and, or）。
```python
# engine/conditions.py
from typing import Dict
from .models import GameState

class ConditionEvaluator:
    """
    负责解析 JSON 中的 condition 字段并返回布尔值
    """
    def check(self, condition: Dict, state: GameState) -> bool:
        if not condition:
            return True
        
        # 处理复合条件
        if "and" in condition:
            return all(self.check(sub_cond, state) for sub_cond in condition["and"])
        
        if "or" in condition:
            return any(self.check(sub_cond, state) for sub_cond in condition["or"])

        # 处理单一条件
        if "attr" in condition:
            attr_name = condition["attr"]
            value = state.attributes.get(attr_name, 0)
            if "min" in condition and value < condition["min"]:
                return False
            if "max" in condition and value > condition["max"]:
                return False
        
        if "has_clue" in condition:
            if condition["has_clue"] not in state.clues:
                return False
        
        if "flag" in condition:
            if condition["flag"] not in state.flags:
                return False
            
        return True
```

### 第三步：引擎核心 (engine/core.py) —— 大脑
这个类不关心画面，只关心逻辑流转。
```python
# engine/core.py
import json
from pathlib import Path
from typing import List, Optional
from .models import GameState, Scene, Option
from .conditions import ConditionEvaluator

class NarrativeEngine:
    def __init__(self, data_path: str = "data"):
        self.data_path = Path(data_path)
        self.state = GameState(current_scene_id="")
        self.scenes: Dict[str, Scene] = {}
        self.config: Dict = {}
        self.evaluator = ConditionEvaluator()
        self.load_all_data()

    def load_all_data(self):
        # 加载配置
        with open(self.data_path / "config.json", "r", encoding="utf-8") as f:
            self.config = json.load(f)
        
        # 初始化属性
        for attr in self.config["attributes"]:
            self.state.attributes[attr] = 50 # 默认值
        
        # 加载场景
        scene_files = (self.data_path / "scenes").glob("*.json")
        for file in scene_files:
            data = json.load(file)
            options = [Option(**opt) for opt in data.get("options", [])]
            scene = Scene(
                id=data["id"],
                speaker=data["speaker"],
                text=data["text"],
                options=options
            )
            self.scenes[scene.id] = scene
        
        # 设定起始场景
        self.state.current_scene_id = self.config["start_scene"]

    def get_available_options(self) -> List[Option]:
        """根据条件过滤出当前可用的选项"""
        current_scene = self.get_current_scene()
        if not current_scene:
            return []
        
        available = []
        for opt in current_scene.options:
            if self.evaluator.check(opt.condition, self.state):
                available.append(opt)
        return available

    def choose_option(self, option_index: int) -> bool:
        """执行选择，返回是否成功"""
        available_options = self.get_available_options()
        if option_index >= len(available_options):
            return False
        
        option = available_options[option_index]
        
        # 1. 应用效果
        for attr, delta in option.effects.items():
            if attr in self.state.attributes:
                self.state.attributes[attr] += delta
        
        # 2. 设置标记
        if option.flag:
            self.state.flags.add(option.flag)
        
        # 3. 给予线索
        if option.give_clue:
            self.state.clues.add(option.give_clue)

        # 4. 检查结局
        if self._check_endings():
            return True
            
        # 5. 跳转场景
        self.state.current_scene_id = option.next
        return True

    def _check_endings(self) -> bool:
        """检查属性是否触顶/触底"""
        for attr, value in self.state.attributes.items():
            if value <= self.config.get("attribute_min", 0):
                self.state.ending_triggered = f"low_{attr}"
                return True
            if value >= self.config.get("attribute_max", 100):
                self.state.ending_triggered = f"high_{attr}"
                return True
        return False

    def get_current_scene(self) -> Optional[Scene]:
        return self.scenes.get(self.state.current_scene_id)

    def get_ending_text(self) -> str:
        if self.state.ending_triggered:
            return self.config["endings"].get(self.state.ending_triggered, "未知结局")
        return ""
```

### 第二步：创建 AI 适配器 (engine/ai_adapter.py)
这是连接两个世界的桥梁。它决定什么时候用引擎，什么时候用 AI。
```python
# engine/ai_adapter.py
from ..ai.simple_ai import SimpleAI
from .core import NarrativeEngine

class AIAdapter:
    def __init__(self, engine: NarrativeEngine):
        self.engine = engine
        self.ai = SimpleAI()
        # 定义哪些前缀属于“系统命令/剧情选择”
        self.command_prefixes = ['查看', '选择', '选项', '问：']

    def process_input(self, user_input: str) -> str:
        """
        处理用户输入的主函数
        """
        stripped_input = user_input.strip()

        # 1. 优先级最高：检查是否是教学指令（教AI说话）
        teach_match = re.match(r'问[：:]\s*(.+?)\s*答[：:]\s*(.+)', stripped_input)
        if teach_match:
            q, a = teach_match.groups()
            return self.ai.learn(q, a)

        # 2. 优先级次高：检查是否是游戏命令或数字选项
        if self._is_game_command(stripped_input):
            return self._handle_game_logic(stripped_input)
        
        # 3. 检查是否命中了当前场景的选项文本（模糊匹配）
        matched_option_index = self._match_option_text(stripped_input)
        if matched_option_index is not None:
            self.engine.choose_option(matched_option_index)
            # 返回下一个场景的文本
            return self._render_current_scene()

        # 4. 兜底：闲聊模式（AI接管）
        return self.ai.respond(stripped_input)

    def _is_game_command(self, text: str) -> bool:
        """判断是否为指令"""
        if text.isdigit():
            return True
        return any(text.startswith(prefix) for prefix in self.command_prefixes)

    def _handle_game_logic(self, text: str) -> str:
        """处理数字选择和查看指令"""
        if text.isdigit():
            index = int(text) - 1
            if self.engine.choose_option(index):
                if self.engine.state.ending_triggered:
                    return f"【结局】{self.engine.get_ending_text()}"
                return self._render_current_scene()
            else:
                return "无效的选择，请重试。"
        
        if text.startswith("查看"):
            attr = text.replace("查看", "").strip()
            if attr in self.engine.state.attributes:
                return f"{attr}：{self.engine.state.attributes[attr]}"
            return "无效的属性名称。"
        
        return "无法识别的命令。"

    def _match_option_text(self, text: str) -> int | None:
        """模糊匹配用户输入和当前选项（模拟聊天点击）"""
        available_options = self.engine.get_available_options()
        for i, opt in enumerate(available_options):
            # 如果用户输入了选项里的关键词，就算选中
            # 比如选项是“派兵镇压”，用户只输入“派兵”
            if opt.text in text or text in opt.text:
                return i
        return None

    def _render_current_scene(self) -> str:
        """将当前场景渲染为字符串"""
        scene = self.engine.get_current_scene()
        if not scene:
            return "场景加载错误。"
        
        response = f"[bold]{scene.speaker}[/]：{scene.text}\n\n"
        options = self.engine.get_available_options()
        for i, opt in enumerate(options):
            response += f"[{i+1}] {opt.text}\n"
        return response
```

class SimpleAICore:
    """
    简易 AI 核心（V2）

    注意：它不知道“属性”、“结局”等业务逻辑，这些由 Engine 控制。
    """
    def __init__(self, restricted_topics: List[str] = None):
        # 1. 基础规则库（模式 -> 回复列表）
        self.rules: Dict[str, List[str]] = {
            r'你好|嗨|hello|hi': ['你好呀，陛下。', '嗨！需要我为您做点什么？'],
            r'谢谢|多谢': ['不客气，这是我的职责。', '愿为您效劳。'],
            r'再见|拜拜|bye': ['再见，祝您安好。', '卑职告退。'],
            r'.*天气.*': ['宫外的天气与我无关，但您的江山社稷才是我的心头大事。'],
            # 兜底回复
            r'.*': [
                '此事还需从长计议，您觉得呢？',
                '嗯，我在听，请继续。',
                '这让我想起了朝堂上的一些传闻……'
            ]
        }
        
        # 2. 动态记忆库（精确问题 -> 回复列表）
        self.memory: Dict[str, List[str]] = {}
        
        # 3. 安全围栏：禁止AI随意讨论的话题（通常由 Engine 传入）
        self.restricted_topics = restricted_topics or []
        
        # 4. 代词反射映射
        self.reflections = {
            "我": "你", "你": "我",
            "我的": "你的", "你的": "我的",
            "我想": "你想", "你想": "我想"
        }

    def _reflect(self, text: str) -> str:
        """简单的代词反转"""
        for k, v in self.reflections.items():
            text = text.replace(k, v)
        return text

    def _match_pattern(self, message: str) -> Optional[str]:
        """匹配规则库，返回回复文本"""
        for pattern, responses in self.rules.items():
            if re.match(pattern, message, re.IGNORECASE):
                reply = random.choice(responses)
                # 处理捕获组（如果有）
                match = re.match(pattern, message, re.IGNORECASE)
                if match and match.groups():
                    reflected = self._reflect(match.group(1))
                    reply = reply.format(reflected)
                return reply
        return None

    def _is_restricted(self, message: str) -> bool:
        """检查是否触及敏感话题"""
        for topic in self.restricted_topics:
            if topic in message:
                return True
        return False

    def respond(self, message: str) -> str:
        """
        对外主接口：生成回复
        """
        if not message.strip():
            return "您在说什么？"

        # 1. 检查是否触及游戏核心机制（由 Engine 决定是否启用此检查）
        if self._is_restricted(message):
            return random.choice([
                "这事涉及国本，建议您查看奏折。",
                "关于此事的决策，恐怕需要您亲自定夺。",
                "我只是个弄臣，不敢妄议朝政。"
            ])

        # 2. 检查精确记忆（用户教过的内容）
        if message in self.memory:
            return random.choice(self.memory[message])

        # 3. 规则匹配
        rule_reply = self._match_pattern(message)
        if rule_reply:
            return rule_reply

        # 4. 最终兜底（理论上上面的 .* 已经兜底了）
        return "臣愚钝，未能领会您的意思。"

    def learn(self, question: str, answer: str) -> bool:
        """
        学习新的问答对
        """
        question = question.strip()
        if not question:
            return False
        
        if question not in self.memory:
            self.memory[question] = []
        
        if answer not in self.memory[question]:
            self.memory[question].append(answer)
            return True
        return False

    def fuzzy_match(self, text: str, threshold: float = 0.6) -> Tuple[bool, Optional[str]]:
        """
        模糊匹配：用于判断用户输入是否像是在说某个关键词
        返回值：(是否匹配成功, 匹配到的原词)
        注意：这里为了简化，使用简单的包含关系。
        实际项目中可替换为 TF-IDF 或编辑距离。
        """
        # 检查是否匹配了记忆中的问题
        for q in self.memory.keys():
            if text in q or q in text:
                return True, q
        
        # 检查是否匹配了规则中的关键词（提取正则中的文字）
        for pattern in self.rules.keys():
            # 提取正则中的普通字符作为关键词
            keywords = re.findall(r'[a-zA-Z\u4e00-\u9fa5]+', pattern)
            for kw in keywords:
                if kw in text:
                    return True, kw
        return False, None

    def export_memory(self) -> str:
        """导出记忆，用于存档"""
        return json.dumps(self.memory, ensure_ascii=False, indent=2)

    def import_memory(self, json_str: str):
        """导入记忆，用于读档"""
        try:
            self.memory = json.loads(json_str)
        except json.JSONDecodeError:
            self.memory = {}

### 这个新版 AI Core 的关键变化：
1. 重命名为 SimpleAICore：强调它是核心组件，不是完整的 App。
2. 构造函数参数 restricted_topics：
    - 引擎在初始化 AI 时，会把 config.json 里的属性列表传进来（如 ["军队", "民心", "国库"]）。
    - 这样 AI 就知道自己不该乱说话的边界在哪里。
3. 移除 main 循环：所有的 input() 和 print() 都删除了，只保留逻辑。
4. 新增 fuzzy_match 方法：这是给聊天界面准备的。当玩家输入“我想谈谈和平”，引擎可以调用这个方法，判断它是否接近选项里的“遣使和谈”，从而实现自然语言点击。
5. 序列化支持 export/import_memory：方便引擎在做存档（Save/Load）时，顺便把 AI 学到的东西一起存起来。
